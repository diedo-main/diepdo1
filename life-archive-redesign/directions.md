# Six candidates and selected direction prototypes

## Common material

Existing Vietnamese story titles, metadata and note language are the primary material. Direction 1 uses a CSS paper-grain field; Direction 2 turns tags and excerpts into an index; Direction 3 uses a CSS waveform. This keeps the archive personal without fabricating photographs or testimonials.

## Candidate cards

1. **Best designer — Irma Boom, book-object thinking.** Treat the search page as a threshold and the reading view as an object with a measured page rhythm. The strongest form is *Quiet Library*; it was selected for a full prototype.
2. **Best designer — Kenya Hara, reductive negative space.** A near-empty charcoal field where one remembered phrase is the entry point. Kept as a thumbnail; its minimalism risks hiding too much search affordance.
3. **Reality reference — Readwise Reader (official page verified: https://readwise.io/read).** Borrow the idea that search, annotations and listening belong in one reading workflow, but not its visual language. The strongest adaptation is *Margin Index*; it was selected for a full prototype.
4. **Reality reference — Internet Archive mobile app listing (verified: https://play.google.com/store/apps/details?id=com.internet.archive.org).** A catalog-first archive metaphor. Kept as a thumbnail because it overweights collection mechanics over intimate reading.
5. **Style wheel — web #08 Cinematic Sound Visualization.** A waveform and playback rhythm can carry an audio-forward archive. The selected translation is *Listening Room*; the waveform is information, not decoration.
6. **Style wheel — east #01 Lu Jingren Bookcraft.** A spread with annotations and carefully constrained columns. Kept as a thumbnail; it overlaps too much with Margin Index after accounting for the existing dark palette.

## Selected prototypes

### Direction 1 — Quiet Library

- **Logic/source:** Book-object thinking, adapted to the existing dark archive palette.
- **Borrowed rule:** A generous reading column, limited chrome, and one calm threshold before the archive reveals itself.
- **Structure:** Search opens from a room-like home; results become stacked slips; notes sit in a quiet, fixed side leaf.
- **Bold move:** A single olive “memory thread” runs from query to result to note.
- **Form:** A remembered phrase becomes the physical thread that takes the owner back to the story.

### Direction 2 — Margin Index

- **Logic/source:** Readwise Reader’s unified reading workflow, validated on its official page; book-margin logic for the presentation.
- **Borrowed rule:** Discovery, reading and annotation are first-class in one continuous workspace.
- **Structure:** A persistent archive index anchors search and filters; reading shares its frame with an editable margin rather than an overlay panel.
- **Bold move:** Notes are shown as active margin fragments that can be promoted or returned to the index.
- **Form:** The owner’s later thought belongs beside the original text, not hidden in a separate utility drawer.

### Direction 3 — Listening Room

- **Logic/source:** Web style-wheel #08, reduced to the archive’s charcoal/olive/ivory system.
- **Borrowed rule:** Let audio progression be a legible structural line, not visual noise.
- **Structure:** The home and results surface duration/voice; the reading view opens with a playable listening strip and a transcript-led body.
- **Bold move:** The waveform doubles as chapter navigation and note anchoring.
- **Form:** These stories often begin as recordings; the shape of listening is the most specific entry into them.
